# AklimeMod

Persönliches WoW Addon für Midnight (12.0.1).

---

## Was das Addon macht

### Interface
- **Elite Frame** — Ersetzt den Eliterahmen mit einem von vier Drachen-Stilen (silber/gold, mit oder ohne Flügel)
- **Seltene Gegner** — Ergänzt den Stern bei seltenen Gegnern durch einen silbernen Drachen
- **Dungeon Eye** — Verschiebt das LFG-Auge an den Minimap-Rand, frei per Drag positionierbar
- **Raid Frame Zentrierung** — Zentriert die Raid-Frames automatisch auf der Bildschirmmitte, passt sich dynamisch an die Gruppengröße an, ignoriert den Bearbeitungsmodus
- **Farbliche Anpassungen** — Ermöglicht das Einfärben von Unit Frames, HUD, Micro Menu, Action Bars und zahlreichen Fenstern (Charakter, Talente, Quest, Map, Loot, Gilde, Freunde, Kalender, Spielmenü u.v.m.)

### Quality of Life
- **Chat kopieren** — Frei verschiebbarer C-Button neben dem Chat öffnet ein Fenster mit der Chat-History zum Markieren und Kopieren
- **Links klickbar** — URLs im Chat werden anklickbar und öffnen ein Kopierfenster
- **Wöchentliche Schatzkammer** — Öffnet das Blizzard-Schatzkammer-Fenster per Knopfdruck
- **Auto Repair** — Repariert Ausrüstung automatisch beim Händler (Gildenbank oder eigenes Gold)
- **Interface Neuladen** — Registriert `/rl` als Kurzbefehl für ReloadUI
- **Einfaches Löschen** — Überspringt die LÖSCHEN/BESTÄTIGEN-Texteingabe bei Items

### Minimap
- **Radialmenü** — Klick auf das Minimap-Icon klappt 4 Buttons auf: PvP Chat Block, Wöchentliche Schatzkammer, Gespeicherte Instanzen, Einstellungen

## Befehle

| Befehl | Funktion |
|--------|----------|
| `/akm` | Einstellungsfenster öffnen |
| `/rl`  | Interface neu laden |
