# AklimeMod

Persönliches WoW Addon für Midnight (12.0.7).

---

## Features

### Interface
- **Elite Frame**: Ersetzt den Eliterahmen mit einem von vier Drachen-Stilen (silber/gold, mit oder ohne Flügel)
- **Seltene Gegner**: Ergänzt den Stern bei seltenen Gegnern durch einen silbernen Drachen
- **Dungeon Eye**: Verschiebt das LFG-Auge an den Minimap-Rand, frei per Drag positionierbar
- **Raid Frame Zentrierung**: Zentriert die Raid-Frames automatisch, passt sich dynamisch an die Gruppengröße an
- **Farbliche Anpassungen**: Einfärben von Unit Frames, HUD, Micro Menu, Action Bars und zahlreichen Fenstern

### Quality of Life
- **Quest Automation**: Nimmt Quests und Belohnungen automatisch an, überspringt Gossipdialoge
- **Quest Tracker**: Eigener Quest-Tracker mit einstellbarer Breite, anklickbaren Quests und Ein-/Ausblenden per Klick
- **ToDo-Liste**: Persistente persönliche Liste, erreichbar per `/akm todo`
- **Chat kopieren**: C-Button neben dem Chat öffnet ein Kopierfenster für den Chatverlauf
- **Links klickbar**: URLs im Chat werden anklickbar
- **Wöchentliche Schatzkammer**: Öffnet das Blizzard-Schatzkammer-Fenster per Knopfdruck
- **Auto Repair**: Repariert Ausrüstung automatisch beim Händler (Gildenbank oder Gold)
- **Interface Neuladen**: `/rl` als Kurzbefehl für ReloadUI
- **Einfaches Löschen**: Überspringt die Texteingabe beim Löschen von Items
- **Händler**: Zeigt 20 Gegenstände pro Seite statt 12

### Gameplay
- **Talent-Erinnerung**: Hinweis wenn man einen Dungeon ohne gewählte Talente betritt
- **Heldentum-Anzeige**: Zeigt an wenn Heldentum / Trommeln aktiv ist
- **Todessound**: Spielt einen Sound beim Tod des eigenen Charakters

### Kontakte
- **Chat verblassen**: Ältere Chat-Nachrichten werden automatisch ausgeblendet
- **Itemlevel im Chat**: Zeigt das Itemlevel von Spielern links neben dem Chatnamen
- **Erweiterte Ignore-Liste**: Blockiert Chat-Nachrichten ignorierter Spieler über das Blizzard-Limit (50) hinaus, mit eigenem Verwaltungsfenster
- **Gruppeneinladungen**: Einladungen automatisch annehmen oder blockieren mit Berechtigungssystem
- **Beschwörungen**: Beschwörungen automatisch annehmen
- **Duellanfragen blockieren**: Lehnt Duellanfragen automatisch ab
- **Haustierkampf blockieren**: Lehnt Haustierkampf-Anfragen automatisch ab
- **Freundesliste**: Erweiterte Darstellung mit Realm, Level und Klasse

### Post
- **Adressbuch**: Speichert Empfänger-Namen für das Postfach, mit Autovervollständigung

### Maus
- **Mauszeiger-Effekte**: Farbiger Ring und Trail-Effekt am Mauszeiger, anpassbar in Farbe, Größe und Stil

### Minimap
- **Radialmenü**: Klappt 4 Buttons auf: PvP Chat Block, Wöchentliche Schatzkammer, Gespeicherte Instanzen, Einstellungen

### Charakter-Tracker
- **Übersicht**: Zeigt gespeicherte Instanzen (Raids) mit Boss-Fortschritt für alle eigenen Charaktere
- **Währungen**: Zeigt alle gesammelten Währungen pro Charakter nach Erweiterung gruppiert
- **Gold**: Goldübersicht über alle Charaktere mit Realm-Summen
- **Instanz-Limit**: Zeigt wie viele Instanzen in den letzten 60 Minuten betreten wurden (Account-Limit: 10/h)

---

## Befehle

| Befehl | Funktion |
|--------|----------|
| `/akm` | Einstellungsfenster öffnen / schließen |
| `/akm help` | Alle Befehle im Chat anzeigen |
| `/akm todo` | ToDo-Liste öffnen / schließen |
| `/akm ignore` | Erweiterte Ignore-Liste öffnen / schließen |
| `/rl` | Interface neu laden |
| `/akmana` | Mana-Warnung Status anzeigen |
| `/akmana test` | Mana-Warnung Testnachricht senden |
| `/akmsell` | Graue Items manuell verkaufen (Fallback) |
